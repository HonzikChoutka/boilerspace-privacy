# BoilerSpace Privacy Policy

This repository exists for one reason: to host the privacy policy for the
[BoilerSpace](https://chromewebstore.google.com/) Chrome extension at a public,
stable URL, as the Chrome Web Store requires.

**Read it here: <https://honzikchoutka.github.io/boilerspace-privacy/>**

It contains no source code. BoilerSpace's source is not public.

The short version: BoilerSpace has no server. It talks only to your own
institution's Brightspace, using the session you are already signed in with, and
everything it remembers stays in your browser. Nothing is collected, transmitted,
or sold.

Questions about the extension, or about this policy, belong in
[Issues](https://github.com/HonzikChoutka/boilerspace-privacy/issues).
